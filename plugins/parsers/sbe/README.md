# Telegraf SBE Parser Plugin

This plugin enables [Telegraf](https://github.com/influxdata/telegraf) to parse [Simple Binary Encoding (SBE)](https://github.com/real-logic/simple-binary-encoding) messages using a `.sbeir` (Intermediate Representation) file generated by the SBE tool. It supports decoding SBE messages, including enums, composites, groups, and variable-length data, and mapping them to Telegraf metrics.

---

## Features

- Loads SBE IR XML at startup.
- Decodes SBE messages on-the-fly using the IR.
- Supports filtering which fields to decode via configuration.
- Handles enums, composites, groups, and var data.

---

## Requirements

- Telegraf (tested with v1.28+)
- Go (for building Telegraf with this plugin)
- Vendored Go OTF decoder from [real-logic/simple-binary-encoding](https://github.com/real-logic/simple-binary-encoding)
- SBE IR file (`.sbeir`) generated by the SBE tool

---

## Configuration

Add the following to your `telegraf.conf`:

```toml
[[inputs.file]]
  files = ["/path/to/sbe/messages"]
  data_format = "sbe"
  ir_path = "/path/to/example-schema.sbeir"
  # Optionally, specify which fields to include (dot notation for nested fields)
  include_fields = ["serialNumber", "modelYear", "someNumbers[0].someNumber", "extras.sunRoof"]
```

- `ir_path` (required): Path to the SBE IR file (e.g., `example-schema.sbeir` generated by the SBE tool).
- `include_fields` (optional): List of fields to decode. If omitted or empty, all fields are included. Use dot notation for nested fields and `[index]` for group elements.

---

## Example: Using [`example-schema.xml`](https://github.com/real-logic/simple-binary-encoding/blob/master/sbe-samples/src/main/resources/example-schema.xml)

Suppose you use the [`example-schema.xml`](https://github.com/real-logic/simple-binary-encoding/blob/master/sbe-samples/src/main/resources/example-schema.xml) from the SBE repo, which defines a message like:

```xml
<message name="Car" id="1" description="A car">
    <field name="serialNumber" type="uint32"/>
    <field name="modelYear" type="modelYear"/>
    <field name="available" type="Boolean"/>
    <field name="code" type="Model"/>
    <group name="someNumbers" dimensionType="groupSizeEncoding">
        <field name="someNumber" type="uint32"/>
    </group>
    <varData name="vehicleCode" lengthType="uint8" characterEncoding="ASCII"/>
    <composite name="extras">
        <field name="cruiseControl" type="Boolean"/>
        <field name="sportsPack" type="Boolean"/>
        <field name="sunRoof" type="Boolean"/>
    </composite>
</message>
```

You can include only `serialNumber`, `modelYear`, `someNumbers[0].someNumber`, and `extras.sunRoof`:

```toml
include_fields = ["serialNumber", "modelYear", "someNumbers[0].someNumber", "extras.sunRoof"]
```

---

## Output

Each SBE message is parsed into a Telegraf metric named `sbe_message` with:
- Tags: `template_id`, `schema_id`, `version`
- Fields: Decoded SBE fields as configured

Example output fields for the above config might look like:

```
sbe_message,template_id=1,schema_id=1,version=0 serialNumber=12345,modelYear=2013,someNumbers[0].someNumber=42,extras.sunRoof=true
```

---

## Building

1. Build Telegraf with the `parsers.sbe` tag:

   ```bash
   go build -tags parsers.sbe ./cmd/telegraf
   ```

---

## Limitations

- Only works with SBE messages compatible with the provided IR XML.
- Filtering is done by field name; nested fields use dot notation.
